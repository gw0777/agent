# 스포츠웰니스경영학 전공교육과정 개발(개편) 보고서 작업

우선순위: 미래라이프대학 교육과정 개발 연구(원고) > 운영방안(안) > 이전 초안. 충돌하면 원고를 따른다.

- `초안_Ⅰ-Ⅶ장.md` — 교무처 양식(Ⅰ~Ⅶ장·부록) 본문 초안 v2 (원고 반영). 교무처 양식 원본은 재업로드 대기.
- `홈페이지_전공정보_입력안.md` — 홈페이지 전공정보 양식 입력안과 31과목 영문명 안 (확인 후 원본 HWP에 입력).
- `outputs/미래라이프대학_교육과정개발연구_원고_수정본.hwpx` — 원고 정정본 (kordoc patch + XML 직접 수정, 서식 보존).
- `data/curriculum.json` — 원고 기준 31과목 83학점 데이터.
- `validate.py`, `test_validate.py` — 인문사회계열 기준 검증과 단위 테스트.

```bash
python3 validate.py              # 통과/위반/대기/예외(승인) 보고 (위반 시 종료 코드 1)
python3 -m unittest -v test_validate
```
