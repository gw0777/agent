# 스포츠웰니스경영학 전공교육과정 개발(개편) 보고서 작업

- `초안_Ⅰ-Ⅶ장.md` — 교무처 양식(Ⅰ~Ⅶ장·부록) 본문 초안. 【자료 대기】/【확인】/【양식】 표시 칸은 추가 자료 업로드 후 채운다.
- `data/curriculum.json` — 트랙·교과목·시수 데이터. `null`은 미확정 값.
- `validate.py` — 인문사회계열 기준 검증(총 학점 78~84, 코어트랙, 실무트랙, 원격 80%(과목 수), 실험·실습 20% 이하, 용어 통일).
- `test_validate.py` — 검증 스크립트 단위 테스트.

```bash
python3 validate.py              # 통과/위반/대기 보고 (위반 시 종료 코드 1)
python3 -m unittest -v test_validate
```
